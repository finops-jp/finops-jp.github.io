テクノロジーカテゴリーは、組織がITリソースやサービスを消費し、支出するテクノロジーの種類を表します。各カテゴリーには、独自の調達モデル、価格体系、コスト可視性の特徴、運用のダイナミクスが存在し、これらがFinOpsの適用方法を決定します。各テクノロジーカテゴリーのページでは、[FinOpsスコープ](http://finops.org/framework/scopes)を定義するための検討事項を説明しています。また、[FinOpsケイパビリティ](http://finops.org/framework/capabilities)が主要な活動をどのようにサポートするか、[FinOpsペルソナ](https://www.finops.org/framework/personas/)がどのように関与するか、どのKPIやメトリクスが成功の測定に役立つか、そして各カテゴリーの請求データと利用データを[FinOps Open Cost and Usage Specification (FOCUS)](http://focus.finops.org)を使用してどのように統合できるかを解説しています。

### SaaS向けのFinOps

組織の価値創造を支援するために、管理対象ソフトウェアの支出をガバナンスし、最適化します。組織は、分散型の購買モデル全体における可視性の向上、アカウンタビリティ（Accountability）の強化、およびデータ駆動型の意思決定を可能にするため、SaaSの利用データにFinOpsケイパビリティを適用します。

[ 詳細を見る ](<https://www.finops.org/framework/technology-categories/saas/>)

### データセンター向けのFinOps

オンプレミス（On-premises）のインフラ投資における可視性と意思決定を向上させます。組織は、キャパシティ、消費、およびビジネス需要を一致させる計画、割り当て、最適化の意思決定をサポートするため、データセンターの利用状況とコストにFinOpsケイパビリティを適用します。

[ 詳細を見る ](<https://www.finops.org/framework/technology-categories/data-center/>)

### データクラウドプラットフォーム向けのFinOps

組織の価値創造を支援するために、従量課金制（Consumption-based）のデータおよび分析の支出をガバナンスし、最適化します。組織は、可視性の向上、共有コンピューティングにおけるアカウンタビリティの強化、およびデータ駆動型の意思決定を可能にするため、ワークロードのテレメトリ（Telemetry）（クエリ、ジョブ、パイプライン、およびプラットフォームのメタデータ）にFinOpsケイパビリティを適用します。

[ 詳細を見る ](<https://www.finops.org/framework/technology-categories/data-cloud-platforms/>)

### AI向けのFinOps

組織は、消費、投資、およびビジネス価値を一致させる割り当て、予測、最適化の意思決定を通じて、コストの複雑さ、開発サイクルの高速化、支出の予測困難さ、そしてイノベーションを支援するためのより高度なポリシーとガバナンスの必要性に対処します。

[ 詳細を見る ](<https://www.finops.org/framework/technology-categories/ai/>)

### パブリッククラウド向けのFinOps

コスト効率、スケーラビリティ（Scalability）、デリバリー速度などのビジネス成果を支援するために、クラウドベースの消費を管理および最適化します。組織は、情報に基づいた意思決定、共有のアカウンタビリティ、およびクラウド投資とビジネス価値の継続的な一致を可能にするため、クラウドの利用状況にFinOpsケイパビリティを適用します。

[ 詳細を見る ](<https://www.finops.org/framework/technology-categories/public-cloud/>)
