# Managing Anomalies Story Collection

Use this collection of Managing Anomalies stories to better understand how other FinOps Practitioners implement this capability. These stories were curated and collected by the Managing Anomalies Working Group. Catch up with them and chat about cloud cost anomalies [in our Slack](<https://finopsfoundation.slack.com/archives/C044FHU7V0X>).
